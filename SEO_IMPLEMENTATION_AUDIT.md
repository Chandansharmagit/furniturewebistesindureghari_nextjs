# SEO Audit and Implementation Roadmap

Site: https://sinduregharifurniture.shop/  
Primary market: Nepal, Kathmandu, Lalitpur, Bhaktapur, Pokhara, Butwal, Chitwan, Biratnagar  
Primary goal: increase organic furniture leads and sales in Nepal.

## Executive Summary

The site already has useful foundations: Next.js App Router metadata, robots.txt, sitemap.xml, JSON-LD, category routes, product routes and product cards. The biggest SEO weakness was that many commercial search intents did not have dedicated crawlable landing pages, product URLs were ID-first, and the sitemap did not include the requested city landing pages or the strongest money-keyword URLs.

Implemented changes in this pass:

- Added crawlable SEO landing pages for sofa set price, wooden beds, wardrobe price, dining tables, office furniture, wooden furniture and custom furniture in Nepal.
- Added local SEO landing pages for Kathmandu, Lalitpur, Bhaktapur, Pokhara, Butwal, Chitwan and Biratnagar.
- Added FAQ, Breadcrumb, CollectionPage and LocalBusiness JSON-LD on new pages.
- Updated product card links to use descriptive product slug URLs.
- Added `/product/[id]/[slug]` route support.
- Updated product metadata titles to use `[Product Name] Price in Nepal | Sindureghari Furniture`.
- Expanded sitemap coverage for money pages, city pages and product slug URLs.
- Added redirects from older generic category paths to stronger SEO URLs.
- Added homepage internal links to commercial and city landing pages.

## Crawl Findings

Live checks completed:

- `/robots.txt`: indexable site, admin/account/cart/checkout paths disallowed, sitemap declared.
- `/sitemap.xml`: present and generated by Next.js. Before this update it listed generic categories and programmatic best pages but not the new city pages or money-keyword pages.
- `/sofas`: metadata and schema present, but much visible product/category content is client-rendered.
- Homepage: contains metadata, schema and category links, but needed stronger commercial anchors and city links.

## Technical Audit

### Title Tags

Status: partially optimized.

Findings:

- Category titles exist but some were generic or duplicated by the global template.
- Product title format was not aligned to the requested pattern.
- Money keywords such as `sofa set price in Nepal`, `wardrobe price in Nepal`, `dining table price in Nepal` needed exact-match landing pages.

Implemented:

- New landing page titles target exact commercial search intent.
- Product metadata now uses `[Product Name] Price in Nepal | Sindureghari Furniture`.

### Meta Descriptions

Status: improved.

Findings:

- Existing category descriptions were useful but not always aligned to buyer intent and city delivery terms.
- Product descriptions pull from API data but fallback text needed Nepal-specific delivery and quality language.

Implemented:

- New category and city pages include unique meta descriptions.
- Product metadata retains API descriptions and stronger fallback copy.

### H1 Tags

Status: improved.

Findings:

- Existing UI category pages have H1s, but client-rendered structure can reduce crawler-visible content.
- Missing exact H1s such as `Sofa Set Price in Nepal` and `Furniture Shop in Kathmandu`.

Implemented:

- Added server-rendered H1s for all new category and city landing pages.

### H2 Structure

Status: improved.

Implemented H2 sections:

- Category pages: buying guide, price factors, customization, delivery, FAQs, internal links.
- City pages: delivery areas, buyer process, local content outline.

### Canonicals

Status: improved.

Implemented:

- New pages have self-referencing canonicals.
- Product slug URLs have canonical URL support.
- Old generic routes redirect to stronger commercial URLs.

### Sitemap

Status: improved.

Implemented:

- Added money-keyword pages.
- Added city landing pages.
- Added product slug URLs.
- Removed redirected generic category URLs from sitemap.
- Updated API fetch fallback from `/api/products` to `/products` if needed.

- Breadcrumb schema

Implemented:

- LocalBusiness schema on city pages.
- Improved product canonical URL in Product schema.

### Page Speed and Core Web Vitals

Status: needs continued monitoring.

Findings:

- Next image optimization is configured for AVIF/WebP.
- Static assets are cached.
- The site uses several client-heavy components and third-party scripts.
- Chatbase chatbot loads sitewide and may affect INP/LCP on mobile.

Recommended next:

- Defer chatbot until after user interaction or after `requestIdleCallback`.
- Convert critical category hero images to `next/image`.
- Keep above-the-fold category content server-rendered.
- Compress Cloudinary images with width and quality parameters.
- Audit bundle size after build.

### Mobile SEO

Status: acceptable but should be retested after deployment.

Checks:

- Viewport meta exists.
- Responsive grids are used.
- New landing page layout uses responsive CSS grid and avoids fixed widths.

### Broken Links

Status: not fully verified locally.

Recommended:

- Run a crawler after deployment and verify 200 status for all sitemap URLs.
- Watch `/category/*` paths where product data may be empty.

### Duplicate Content

Status: improved.

Findings:

- `/sofas`, `/beds`, `/wardrobes`, `/dining-tables`, `/office-furniture` and new money pages could compete if both indexed.

Implemented:

- Redirected old generic paths to stronger canonical URLs.
- Removed those old paths from sitemap.

### Thin Content

Status: improved.

Findings:

- Product/category pages depend heavily on client-rendered product data.
- Some category pages have thin server-visible HTML.

Implemented:

- Added server-rendered long-form content to commercial and local landing pages.

### Indexability

Status: improved.

Implemented:

- New indexable routes with metadata, canonical, schema and sitemap inclusion.
- Non-commercial/account paths remain disallowed.

## Prioritized Roadmap

### Critical

- Deploy the new SEO routes, sitemap and redirects.
- Submit updated sitemap in Google Search Console.
- Replace placeholder Google verification code in `src/app/layout.js`.
- Verify redirects do not break paid/social campaigns that still use old URLs.
- Make product API stable for sitemap generation.

### High

- Convert hero/product imagery to optimized WebP/AVIF with meaningful filenames and alt text.
- Add server-rendered product summary blocks for product pages so crawlers see product description, features, specs and FAQs before hydration.
- Add Google Business Profile and real NAP details consistently across site.
- Build category-specific FAQs into visible page copy for all major categories.

### Medium

- Add review schema only when real review data is available.
- Build city pages beyond the first six: Biratnagar is already added because it is a target location.
- Add blog posts from the topic list below with internal links to product/category pages.
- Add breadcrumbs visibly on product pages.

### Low

- Add `hreflang` for English/Nepali page variants if Nepali pages are created.
- Build a furniture glossary for wood types, finishes, sizing and maintenance.
- Add downloadable measurement checklist PDF.
